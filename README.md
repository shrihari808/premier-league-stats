## 📖 About the Project

This project originally started as a standalone backend REST API developed to revise, practice, and sharpen my **Spring Boot** and **Java** skills. It has since evolved into a complete, end-to-end full-stack application backed by a cloud PostgreSQL database and an interactive web interface.

---

## 📊 Data Source

The player statistics dataset used in this project was scraped from [FBref Premier League Stats](https://fbref.com/en/comps/9/stats/Premier-League-Stats).

It encompasses comprehensive metrics across all 20 Premier League clubs, including:
* Standard statistics: Appearances (`mp`), Starts (`starts`), Minutes (`min`), Goals (`gls`), Assists (`ast`), Penalties (`pk`).
* Advanced metrics: Expected Goals (`xg`), Expected Assisted Goals (`xag`).
* Disciplinary records: Yellow cards (`crdy`), Red cards (`crdr`).

The dataset is bundled within the backend and automatically ingested into PostgreSQL on initial startup via a Spring Boot `CommandLineRunner` seeder.

## ⚙️ Backend Endpoints

The backend exposes a RESTful API at `/api/v1/player` with pagination, dynamic sorting, and multi-attribute filtering using Spring Data JPA Specifications.

| HTTP Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/v1/player` | Query players with pagination, sorting, and dynamic multi-criteria filters. |
| `GET` | `/api/v1/player/{playerName}` | Retrieve complete statistics for a single player by name. |
| `POST` | `/api/v1/player` | Add a new player record to the database. |
| `PUT` | `/api/v1/player` | Update statistics for an existing player. |
| `DELETE` | `/api/v1/player/{playerName}` | Delete a player record by name. |

### Query Parameters for `GET /api/v1/player`:
* **Filtering:**
  * `name`: Partial name search (case-insensitive)
  * `team`: Filter by club (e.g. `Arsenal`, `Manchester-City`)
  * `position`: Filter by position (e.g. `FW`, `MF`, `DF`, `GK`)
  * `nation`: Filter by 3-letter nationality code (e.g. `ENG`, `BRA`, `FRA`)
  * `minGoals`: Minimum goals scored threshold
  * `minAssists`: Minimum assists threshold
  * `minMinutes`: Minimum minutes played threshold
* **Pagination & Sorting:**
  * `page`: Zero-indexed page number (default: `0`)
  * `size`: Number of records per page (default: `20`)
  * `sort`: Sorting field and direction (e.g. `gls,desc`, `ast,desc`, `min,desc`)

### Interactive API Documentation:
* **Swagger UI:** `/swagger-ui.html`
* **OpenAPI Specification JSON:** `/v3/api-docs`

## 🚀 Running Locally with Docker

You can run the entire backend and PostgreSQL database locally with a single command without needing Java or PostgreSQL installed on your machine:

```powershell
# 1. Clone the repository
git clone https://github.com/shrihari808/premier-league-stats.git
cd premier-league-stats

# 2. Start PostgreSQL and Spring Boot API via Docker Compose
docker compose up --build
```

* API will be available at: `http://localhost:8080/api/v1/player`
* Swagger UI at: `http://localhost:8080/swagger-ui.html`
